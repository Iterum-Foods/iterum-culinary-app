## 🎯 **How to Use**

### **Method 1: Search USDA Database**

1. Click **"Enhanced Import"** button
2. Enter search term (e.g., "olive oil")
3. Click **"Search"**
4. Select ingredients to import
5. Done!

### **Method 2: Bulk Import**

1. Download USDA dataset: https://fdc.nal.usda.gov/download-datasets.html
2. Click **"Enhanced Import"** button
3. Click **"Upload USDA Bulk File"**
4. Select downloaded JSON file
5. Wait for processing
6. Done!

### **Method 3: Base Database**

1. Click **"Import Base Database"** button
2. Import 145 professional ingredients
3. Done!
