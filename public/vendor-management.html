Vendor & purchasing hub

Build your supplier list, then tune ingredient unit costs for this project so menu and recipe costing match reality. When signed in, data syncs to the cloud; cloud values win on merge.

Three quick steps

1 Add vendors (or import) so you have a supplier to attach to items.
2 Upload a PDF/CSV price list — SKUs land on that vendor, then become an order guide or recipe stubs.
3 Match names to ingredients so recipe costing lines up.
Tied to costing: ingredient names should match the master ingredient library; price overrides flow into recipe and menu math. Open ingredient library

Onboarding: suppliers, then costs

  1. Directory — Open your vendor list and add or import suppliers.
  2. Adjust pricing — Use workspace price overrides for the ingredient + vendor pair; names should match the ingredient library for best results.
  3. Fine-tune — Use Edit on a vendor row to change contact or notes; use Adjust in the price table to change a locked-in unit cost.
