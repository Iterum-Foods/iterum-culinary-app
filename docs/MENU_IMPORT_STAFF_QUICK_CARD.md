# Menu import — staff quick card

**One page · print-friendly · ~5 minutes**

---

## Before you start

- [ ] Signed in to Iterum
- [ ] Correct **project** selected (sidebar)
- [ ] Menu in **Excel** (`.xlsx`) with a header row

## Spreadsheet header row (copy/paste)

`Category` · `Item` · `Description` · `Price` · `Allergens` · `Tags`

*(Use the closest names you have; extra columns are usually fine.)*

## In the app

- [ ] Open **Menu Builder** (`menu-builder.html`)
- [ ] Choose import / upload your file
- [ ] Map columns if prompted
- [ ] Run import → **save**

## Quick QA

- [ ] Spot-check **3 items** (name, price, category)
- [ ] Open one item → **allergens / notes** look right
