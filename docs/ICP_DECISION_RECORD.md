## Decision (locked 2026-09-16 — 90-day ICP)

| Field | Value |
|--------|--------|
| **Chosen segment (primary)** | **Single professional user** — **chef** (BOH / R&D / launch) **or** **bartender / bar lead** using Iterum themselves on **one** workspace. |
| **Secondary (opportunistic only)** | Independent chef-owner or bar program; consultant with **one** active client workspace. Say no to deals that require org connecting, SSO, or ERP before solo value is proven. |
| **Phase 2 (explicit defer)** | Multi-unit **2–8 venues**, org hierarchy, cross-site compare as a **sales** promise — after solo retention. |
| **Rationale (one paragraph)** | Develop + Shift + Archive already serve one cook or bartender. Multi-unit and shared-vendor complexity blocked “finished and operational.” First market proof = one person getting daily value; existing `projectId` / members model remains the foundation for org connecting later. |
| **Explicit non-goals for 90 days** | **No** multi-venue connecting as a pilot promise. **No** enterprise SSO. **No** POS/ERP. **No** teammate/RBAC polish as a launch gate. **No** data warehouse. **No** automated email invites. Firestore export + backup remain the Archive story. |
