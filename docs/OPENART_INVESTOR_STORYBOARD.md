# OpenArt — investor teaser (script + storyboard)

**Product:** Iterum Culinary (Iterum Foods)  
**Length:** ~90 seconds · **16:9** · stitch clips in CapCut or Descript  
**Story:** One chef and one bartender. Organize the kitchen, run the shift, keep the archive. Not an enterprise pitch.  
**Do not show:** fake revenue, multi-site org charts, POS, or invented logos. Add titles in the editor. AI video mangles on-screen text.

**How to use OpenArt**

1. **Storyboard stills:** [AI Storyboard](https://openart.ai/features/ai-storyboard-generator/) — paste one **Still prompt** per shot.  
2. **Motion:** [Text to Video](https://openart.ai/features/ai-text-to-video/) or [Smart Shot](https://openart.ai/features/smart-shot/) — paste the **Video prompt**. Smart Shot is best for 10–20s multi-cut scenes (shots 2, 4, 8).  
3. **Director:** paste the **Director brief** below first, then generate one shot at a time so faces stay consistent. Save the chef and bartender in Character Builder and reuse them.  
4. **Product shots (4 and 7):** upload a real screenshot from `https://iterum-culinary-app.vercel.app/` (dashboard or recipe library) as the reference image. Do not let the model invent the UI.

**Look lock (put this at the start of every prompt)**

```text
Cinematic, photoreal, 16:9. Warm independent restaurant, not a chain. Teal-green and cream color grade, soft copper highlights. Natural skin, no plastic look, no logos, no readable UI text unless a reference screenshot is attached. Shallow depth of field, gentle camera move only.
```

**Characters**

- **Chef Mara:** woman, early 30s, short dark hair, clean white chef coat, calm, small wood-and-steel kitchen.  
- **Bartender Jules:** man, early 30s, black shirt, sleeves rolled, wood bar, amber bottles, evening light.

## Voiceover (record this; ~150 words, ~85 seconds)

Most kitchen software is built for chains. Chefs and bartenders still run the real work in notes, group chats, and spreadsheets.

Iterum Culinary is a kitchen operating system for one professional. One workspace. Recipes, menus, and costs in the same place.

Develop the menu before service. Run the shift with logs and checklists on the phone you already carry. Archive the work so it stays yours — export it, back it up, take it with you.

The same account covers the bar: cocktails, pars, and the shift.

We are starting with the person on the line. Not a corporate rollout. One chef. One bartender. A system they will actually open tomorrow.

Iterum Culinary. Your kitchen, organized — and yours to keep.
