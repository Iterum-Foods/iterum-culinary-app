# Pilot note — online required (shift app)

**Audience:** Operators and COO during first 1–3 kitchen pilots.

The **mobile shift app** (`mobile-compliance.html`) requires an **internet connection** for:

- Workspace list and membership  
- Publishing menus, bar packs, and checklists to Firestore  
- Temperature and sanitizer logs synced with the dashboard  

**Not in this pilot:** offline queue with automatic sync when back online.

**Staff guidance:** If the app shows load errors, check Wi‑Fi or cellular data before reporting a bug.

**Managers:** Publish menus and bar content from the office web app while online; ask staff to refresh the shift app after publishing.
